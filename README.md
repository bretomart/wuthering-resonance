# Wuthering Resonance

Wuthering Resonance is a character synergy and team composition builder for Wuthering Waves.

## Features

- **Resonator Rosters:** Full roster coverage of Resonators categorized by attribute (Spectro, Havoc, Aero, Fusion, Electro, Glacio) and weapon type.
- **Intro & Outro Skill Synergies:** Visual mapping of concerto energy rotations, attack buffs, and elemental amplification chains.
- **Echo & Sonata Matching:** Quick reference for optimal Sonata sets and main Echo skills for primary DPS and sub-DPS setups.
- **Client-Side Performance:** Built with Vite, TypeScript, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
npm run build
```
